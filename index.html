01. About me

      

        

          
I'm Nimrod P. Pala, a Computer Science student from Butuan City. What keeps me coding is curiosity. I like opening up how something works, whether that's a pointer in C, a render loop in Three.js or a database behind a booking system, and then building my own version of it.

          
Most of what I know comes from projects. I've led the front end of a university library system, written a native Windows desktop app in C++, built a 3D tower defense game in plain JavaScript and made a set of animated visualizers that help classmates learn C. I also like building random things I think will be useful, like a Minecraft skin editor or a personal world news feed.

          
I'm currently learning Python. After I graduate I want to work with hardware too: building physical things with my own hands and then writing the code that brings them to life.

          
Off the keyboard I play chess competitively and I'm a big One Piece fan.

PageVoice

          

          
A desktop app that turns EPUB, PDF and TXT books into audiobooks, fully offline. It cleans out page numbers, headers and footnote markers first (and shows you every removal so you can undo it), then reads the book with the Kokoro neural voice on your CPU and exports an M4B with chapters or MP3s. It also supports pronunciation lists and resuming a render after closing the app.

          
  • Python
  • Kokoro TTS
  • ffmpeg
  • uv
  • pytest

C Visualizers

          

          
Three animated, interactive walkthroughs for learning C, sharing one animation engine. The C code highlights line by line while bytes, stack frames and pointers move on screen. Topics include Fundamentals (types, pointers, memory), Data Structures (BST, linked list, heap, hash table…) and Recursion (call stack, Hanoi, merge sort, backtracking).

  • C
